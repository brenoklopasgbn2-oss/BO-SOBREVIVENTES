CHAMPIONS Z - BOT DO DISCORD
============================

PRIMEIRO TESTE
1. Configure a variavel TOKEN no Railway.
2. O bot precisa estar no Discord com permissao Administrador.
3. Inicie com: npm start
4. No Discord, use /setup.
5. O /setup cria/renomeia a estrutura, aplica os cargos e publica os paineis.

CARGOS CRIADOS
- 👑 Dono
- 🛡️ Staff
- 🎧 Suporte
- 🎥 Streamer
- 💎 VIP
- 🏆 Champion
- 🤖 Champions Z

IMPORTANTE
- Novos membros recebem o cargo 🏆 Champion automaticamente.
- A imagem champions-z-bem-vindo.png ja esta dentro de assets/painels.
- Regras antigas da RAID-Z/ZONA-Z nao sao reutilizadas no painel novo.
- O bot mantem aliases dos nomes antigos apenas para conseguir renomear/migrar a estrutura existente.
- Depois do primeiro teste, ajuste manualmente quem deve receber Staff, Suporte, Streamer e VIP.
