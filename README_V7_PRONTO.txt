SobreviventesZ Web Store v7

O que tem:
- Site com hover 3D forte no card inteiro do produto.
- Sons no hover e na confirmação de compra.
- Botão/aviso para ativar som no navegador.
- Confirmação obrigatória antes de comprar.
- Produto/kit com vários itens.
- Admin escolhe tipo de entrega:
  * drop_box = entrega em caixa temporária
  * drop_at_feet = dropa direto no chão (use para carro, plank, log, barril grande)
  * account_unlock = virtual/VIP
- O mod v11 agrupa itens da mesma compra na mesma caixa. Se lotar, cria outra caixa.

Atualizar no Railway:
1. Extrair este ZIP.
2. Substituir os arquivos no GitHub da loja.
3. Commit + push.
4. Railway faz deploy.
5. Entrar no admin e editar produtos antigos para escolher tipo de entrega.

Importante:
- Navegador só toca som depois de um clique do player. Por isso tem botão "Ativar sons da loja".
- Para kit pequeno, use drop_box.
- Para WoodenPlank, carro, log, itens grandes ou que não cabem em caixa, use drop_at_feet.
