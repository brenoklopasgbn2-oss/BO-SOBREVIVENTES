V22 - CORREÇÃO VEÍCULOS / SEGURO / GARAGEM

Correções:
- Veículo comprado/alugado agora cria entrega que o mod v20 consegue dropar.
- Antes estava deliveryType=rental_vehicle e o mod v20 tratava como virtual, por isso não dropava.
- Agora vai como deliveryType=drop_at_feet, mas o meta continua com todos os dados do veículo completo para o mod novo montar peças.
- Compra permanente SEM seguro não fica aparecendo em Minha Garagem.
- Compra permanente COM seguro fica na garagem para reposição.
- Aluguel fica na garagem.
- Minha Garagem mostra dados: usos do seguro na semana, total usado, entregas criadas, último uso.
- Admin mostra dados dos veículos e usos do seguro.
- Player pode adicionar/trocar/upgrade de plano de seguro.
- Cards de veículos ficaram proporcionais e animados como os itens normais.

IMPORTANTE:
Com o mod v20 atual, o veículo volta a dropar no chão.
Para montar peças automaticamente, precisa do próximo mod com leitura do meta vehicle_full_mounted.
