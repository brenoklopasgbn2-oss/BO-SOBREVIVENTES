V35 - Ranking, Clãs, Troféus PNG, Pontos e Wipe seguro

Correções desta versão:

1) Finalizar temporada agora exige senha admin
- Para fechar uma temporada o admin precisa digitar a mesma senha usada para entrar no painel do site.
- Evita finalizar temporada sem querer ou por alguém que pegou o painel aberto.

2) Player não troca bandeira do clã
- Dono/sub dono ainda consegue editar descrição, adicionar/remover membros e definir sub dono.
- Bandeira/imagem do clã só pode ser alterada pelo admin.

3) Troféus do clã agora aceitam PNG/link de imagem
- O admin pode colocar uma URL PNG do troféu.
- Também pode manter emoji/ícone reserva caso não tenha imagem.
- Cada troféu tem título, descrição, evento/temporada, cor e pontos.

4) Pontos por troféu
- Quando o admin dá troféu para um clã, pode informar pontos.
- Esses pontos entram no score do clã.
- Também são enviados para os membros do clã como badge/troféu de player, se a opção estiver marcada.

5) Player recebe troféu visível no ranking
- Ao premiar um clã, todos os membros ativos podem receber o mesmo troféu.
- O ranking de players mostra mini troféus e pontos de troféu.
- A área de troféus/badges mostra imagem, descrição e pontos.

6) Admin consegue apagar clã
- Tem botão dentro do painel admin do ranking.
- Exige senha admin.
- Apaga o clã, membros e troféus daquele clã.

7) Wipe do ranking com senha
- O admin pode limpar as kills do ranking Global, só Vanilla ou só BBP.
- Exige senha admin e confirmação digitando WIPE.
- O wipe não apaga clãs, bandeiras, campeões nem troféus.

8) Visual animado
- Troféus PNG/ícones ficam com brilho, sweep e efeito 3D leve.
- Chips dos clãs e badges dos players ficam mais destacados.

IMPORTANTE:
- Esta versão é só do site.
- O mod ainda precisa ser feito depois para enviar kills reais para /api/game/kills.
