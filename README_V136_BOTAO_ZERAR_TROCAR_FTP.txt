RAID-Z STORE V136 - BOTÃO PARA ZERAR E TROCAR O FTP
=====================================================

NOVO NO PAINEL ADM:
- Acesse /admin/ftp.
- Clique em “Zerar FTP para cadastrar outro”.
- Confirme o aviso do navegador.
- Os campos de host, usuário, senha, porta e caminho ficam limpos/desativados.
- Depois preencha os dados do novo FTP e clique em “Salvar FTP”.

O RESET NÃO APAGA:
- compras;
- moedas dos jogadores;
- entregas pendentes;
- veículos, VIPs ou trajes;
- arquivos existentes no FTP antigo;
- dados do PostgreSQL fora das configurações do FTP.

O RESET APAGA SOMENTE:
- configuração de conexão FTP salva;
- senha FTP criptografada;
- último status de saúde;
- último diagnóstico FTP.
