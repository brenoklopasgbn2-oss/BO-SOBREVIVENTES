V10 - Correção visual da loja

O que foi ajustado:
- A página inicial / agora abre a loja no mesmo visual premium, sem aparecer logo gigante quebrada.
- /shop também abre mesmo sem Steam64, para o player conseguir ver a loja antes de cadastrar.
- O cadastro Steam64 aparece dentro da loja quando o player ainda não entrou.
- CSS crítico foi colocado direto no HTML para evitar problema de cache/estilo não carregando no Railway.
- Logo do topo recebeu tamanho fixo para nunca estourar a tela.
- Vanilla usa card vermelho e BBP usa card azul.
- HUD de saldo, categorias, busca e cards 3D foram reforçados.

Depois de atualizar no GitHub/Railway:
1. Aguarde o deploy finalizar.
2. Abra o site e pressione CTRL + F5.
3. Se ainda aparecer antigo, limpe cache do navegador ou abra guia anônima.
